# لقطات الهاتف — وسيط

ست صور PNG، كل صورة 1080 × 1920 بكسل بنسبة 9:16، وأقل من 8 ميغابايت.

الترتيب المقترح للعرض:

1. `01-merchant-home.png`: الصفحة الرئيسية للتاجر.
2. `02-sales-products.png`: منتجات موظف المبيعات.
3. `03-create-order.png`: مراجعة طلب قبل إنشائه.
4. `04-management-orders.png`: طلبات الإدارة.
5. `05-delivery-orders.png`: طلبات مندوب التوصيل.
6. `06-login.png`: تسجيل الدخول.

التقطت الصور مباشرة من واجهات المشروع في نسخة Expo Web باستخدام Chromium بأبعاد هاتف، وليست لقطات من جهاز Android أو AAB. البيانات المعروضة توضيحية محلية؛ لم يُستخدم حساب حقيقي أو يُتصل بخادم الإنتاج أو يُرسل طلب. لم تُرسم واجهات بديلة باستخدام الذكاء الاصطناعي. قد تختلف بعض تفاصيل العرض عن النسخة الأصلية للهاتف؛ راجع مطابقتها لبناء Android الذي سترفعه قبل النشر.

لإعادة الالتقاط من الكود الحالي:

```sh
npx expo export --platform web --output-dir /tmp/waseet-store-preview
node scripts/capture-store-screenshots.mjs /tmp/waseet-store-preview
```

السكربت يشغّل خادمًا محليًا مؤقتًا على منفذ تلقائي ثم يغلقه والمتصفح. يتحقق من المقاس والحجم وأخطاء JavaScript وغياب رسائل الخطأ قبل الحفظ. لا يعدل مكونات التطبيق.

ارفع ملفات PNG إلى قسم لقطات شاشة الهاتف. ملف ZIP المجاور مخصص لتنزيل المجموعة وفكها فقط، ولا يُرفع بدل الصور في Play Console.
