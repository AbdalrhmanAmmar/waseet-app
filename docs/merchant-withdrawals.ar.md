# طلبات سحب التاجر

- يظهر زر «طلب سحب» في كارت الرصيد بالرئيسية وحسابي للتاجر فقط، ويفتح `/merchant/withdrawal`.
- الشاشة تدعم إدخال المبلغ بالأرقام العربية والإنجليزية حتى منزلتين عشريتين، ونسب 25% و50% و75% وكامل الرصيد، وملاحظة مطلوبة يتحقق منها Zod برسالة عربية قبل الإرسال.
- يلزم مبلغ أكبر من صفر ولا يتجاوز `dollarBalance` المؤكد. الرصيد الغائب أو الفاشل تحديثه لا يُعامل على أنه صفر، ويمنع التأكيد حتى تحديثه.
- قبل الإرسال تظهر مراجعة للمبلغ والملاحظة. يعاد جلب `GET User/{userId}` للتحقق من الرصيد وهوية الحساب، ثم يرسل `POST withdrawal-requests` عبر عميل API الحالي وتوكن الجلسة، بجسم `{ amount, note }` فقط.
- يستخدم التطبيق مسار الخادم الموثق `withdrawal-requests`. لم تضف مسارات لسجل الطلبات أو بيانات بنكية غير متاحة.
- يمنع الضغط المتكرر أثناء الإرسال. عند نجاح الخادم يظهر تأكيد إرسال الطلب ويعاد جلب الحساب، دون خصم محلي أو ادعاء اكتمال التحويل.
- رفض الخادم يبقي المدخلات. خطأ الشبكة أو مهلة الإرسال أو خطأ 5xx بعد محاولة POST يعتبر نتيجة غير مؤكدة؛ تمنع إعادة الإرسال في جلسة التطبيق الحالية حتى التحقق مع الدعم. حالة المنع ليست سجلًا دائمًا وتزول مع إعادة تشغيل التطبيق/تسجيل الخروج.

## مسؤولية الخادم

يجب أن يفرض الخادم ملكية الحساب وصلاحية الدور والتحقق من الرصيد بشكل ذري، ويمنع تكرار الطلبات/حجز رصيدها وفق قواعده. إعادة قراءة الرصيد من التطبيق لا تمنع سباق الطلبات من جهازين. لم نضف مفتاح idempotency لأن عقد API المقدم لا يذكر دعمه.

## التحقق

اختبارات وحدة لتحويل الأرقام والتحقق من حدود المبلغ، واختبارات واجهة بمحاكاة API للإرسال والمراجعة وتغيّر الرصيد وأخطاء الخادم. الاختبارات لا ترسل طلبات سحب مالية حقيقية.
