# إعادة تصميم تسجيل الدخول

تم تنفيذ الشاشة المرجعية بمكونات React Native قابلة للاستخدام: خلفية عاجية، أقواس ونقاط خافتة، شعار وسيط في المنتصف، ترحيب مختصر، بطاقة بيضاء للحقول وزر الدخول، وزر منفصل بإطار أخضر لإنشاء الحساب.

## تفاصيل التصميم

- الخلفية `#F8F6F2`، الزر الرئيسي `#10584F`، العناوين `#104D44`، مع خط Tajawal المتاح في المشروع.
- استخدام شعار وسيط الأصلي، لأن الشعار في الصورة المولدة تقريب بصري للهوية. الأقواس والنقاط مرسومة بعناصر الواجهة ولا تعتمد على صورة خلفية كبيرة.
- العنوان «أهلًا بعودتك» والوصف «سجّل دخولك لمتابعة أعمالك مع وسيط.» كما في المعاينة.
- الحقول بتسميات ثابتة، أيقونة بريد وقفل على اليمين، وأيقونة إظهار كلمة المرور على اليسار. حدود الحقل تتغير عند التركيز أو الخطأ.
- زر الدخول زمردي عريض بسهم لليسار، وزر إنشاء الحساب بإطار أخضر أسفل عبارة «ليس لديك حساب؟».
- إزالة «نسيت كلمة المرور» من شاشة الدخول، والمقدمة التسويقية السابقة، وتكرار عنوان الدخول، وسطر الأدوار أسفل الصفحة.
- لا تُرسم ساعة أو شريط حالة أو مؤشر Home زائف داخل الشاشة؛ هذه الأجزاء يعرضها نظام الهاتف نفسه.

## السلوك والبيانات

الربط مع تسجيل الدخول ومخطط التحقق والتوكن والتوجيه حسب الدور مستمر. رسائل الحقول تظهر أسفلها، وخطأ الخادم يظهر داخل بطاقة الدخول. يبدأ الإدخال التالي بمسح رسالة الخادم السابقة.

البريد يدعم الملء التلقائي ولوحة مفاتيح البريد، وزر «التالي» ينقل التركيز إلى كلمة المرور. كلمة المرور تدعم الملء التلقائي والإظهار والإخفاء دون فقد القيمة، وزر لوحة المفاتيح يرسل النموذج. النص العربي الفارغ محاذاته يمينًا، والقيمة المكتوبة اتجاهها يسار إلى يمين.

أثناء الطلب يظهر «جارٍ تسجيل الدخول…» ومؤشر تحميل، وتُعطل الحقول وزر إنشاء الحساب. حارس فوري يمنع تكرار الإرسال حتى قبل اكتمال تحديث الواجهة. عند وصول رفض أو انتظار موافقة تظهر شاشة حالة الحساب المناسبة، وتُمسح كلمة المرور وتعود مخفية عند الرجوع.

## التجاوب والتنظيم

المحتوى في المنتصف بعرض أقصى 440 نقطة مع مسافات آمنة وتمرير رأسي. الشاشة تتحرك مع لوحة المفاتيح على iOS وتبقى قابلة للتمرير عندما يقل الارتفاع. الخط قابل للتكبير، والزر لا يعتمد على ارتفاع ثابت يمنع تمدد النص. جميع الأزرار الأساسية لها مساحة لمس 44 نقطة أو أكثر.

- `src/screens/auth/Login/index.tsx`: ترتيب الشاشة وربط النموذج والتنقل وحالة الطلب.
- `src/screens/auth/Login/styles.ts`: استبدال الأنماط القديمة غير المستخدمة بأنماط الشاشة الجديدة.
- `src/screens/auth/Login/LoginField.tsx`: مكوّن حقول الشاشة، وحالة التركيز والخطأ ومرجع الإدخال للتحكم في التركيز.
- `tests/e2e/login.spec.ts`: التحقق من التفاعل، والتجاوب، وإزالة رابط الاستعادة، والانتقال للتسجيل.

## المعاينات والتحقق

نجحت فحوص TypeScript وESLint وPrettier وفحص Git diff، و26 اختبار وحدة. اجتاز 26 سيناريو للأدوار وحالات الحساب، وسيناريوهان مخصصان للشاشة والتفاعل (28 سيناريو واجهة إجمالًا). اكتمل تصدير Web وiOS وAndroid.

شملت المراجعة مقاسات 320×640 و390×844 و768×1024، والوصول إلى زر الدخول عند تقليل ارتفاع الشاشة إلى 400. المقاس الصغير يتيح التمرير للوصول إلى إنشاء الحساب.
