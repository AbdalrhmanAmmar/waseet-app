# هوية وسيط: الأيقونة وشاشة البداية

اعتمد التطبيق شعار Dashboard الأصلي. نسخة SVG مستقلة داخل المشروع في `assets/branding/logo.svg`، فلا يحتاج المشروع إلى مجلد dashboard عند البناء.

## الأصول المستخدمة

| الملف ضمن assets/images | الغرض |
| --- | --- |
| app-icon.png | أيقونة 1024×1024 بخلفية كاملة غير شفافة، دون قص الزوايا؛ يستخدمها iOS وAndroid القديم |
| android-icon-foreground.png | طبقة أمامية شفافة 1024×1024 بهوامش للـAdaptive Icon |
| android-icon-monochrome.png | نسخة شفافة أحادية اللون للأيقونات الملوّنة حسب ثيم Android، مع فواصل المكعب مفرغة |
| splash-icon.png | شعار شفاف 1024×1024 لشاشة البداية |
| brand-logo.png | نسخة شفافة 512×512 للشعار داخل الواجهات |
| favicon.png | أيقونة ويب 64×64 مطابقة لشعار Dashboard |

الألوان الأصلية محفوظة: أخضر `#147D64` وبرتقالي `#F29A4A` وخلفية فاتحة `#F8FAF7`. شاشة البداية تعرض الشعار في المنتصف بعرض 180 على الخلفية الفاتحة. لم تتم إضافة اسم نصي داخل الصورة حتى يحتفظ الرمز بوضوحه ويتلاءم مع قيود شاشة البداية في Android.

[معاينة الأصول](branding-preview.png) تعرض الأيقونة، وقناعي Android، وتكوين شاشة البداية. هذه معاينة تصميمية وليست لقطة من native build.

## إعادة التوليد

```sh
npm run assets:generate
```

السكربت `scripts/generate-brand-assets.mjs` يستخدم Sharp لتحويل الأصل المتجهي مباشرة إلى PNG؛ لا يكبّر favicon منخفض الدقة. ملفات PNG الناتجة محفوظة في Git وجاهزة للبناء، ولا يحتاج التطبيق إلى Sharp أثناء التشغيل.

للتعديل على الهوية، عدّل SVG ثم أعد التوليد. خلفية شاشة البداية وطبقة Android مضبوطة كذلك في `app.json`، ويجب تحديثها إذا تغير لون خلفية الهوية. عند تغيير هندسة الشعار، راجع الهوامش والقناع الأحادي بصريًا؛ السكربت يتعامل مع فواصل المكعب في الأصل الحالي.

## مشاهدة التغيير

- الشعار داخل الواجهات: يظهر بعد إعادة تحميل التطبيق؛ عند استمرار cache قديم شغّل `npm start -- --clear`.
- أيقونة الويب: أعد تحميل المتصفح، وقد تحتاج لمسح favicon المخزن.
- أيقونة الهاتف وشاشة البداية الأصلية: تحتاج بناء جديد وتثبيته. Hot Reload لا يغير الأصول الأصلية داخل نسخة مثبتة.
- Expo Go يعرض أيقونة التطبيق بدل شاشة البداية المخصصة، وdevelopment builds لا تحاكي كل خصائصها. اختبر الشكل النهائي باستخدام release build كما توصي [وثائق Expo SDK 57](https://docs.expo.dev/versions/v57.0.0/sdk/splash-screen/).

إعداد الهوامش مستند إلى [إرشادات Android للأيقونات المتكيفة](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive): طبقة 108×108 ومساحة آمنة مركزية 66×66.
