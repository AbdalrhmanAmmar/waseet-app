# أرقام التواصل في الطلبات

- إنشاء الطلب يحدد نوع التوصيل من المنطقة قبل التحقق من الهاتف. النوع غير المعروف يمنع المراجعة حتى اختيار منطقة محددة النوع.
- الهاتف الأساسي مطلوب. الداخلي يقبل أي نص غير فارغ ويحافظ على الصيغة؛ الخارجي يشترط `09` ثم ثمانية أرقام. الأرقام العربية والفارسية تقبل وتحوّل للإنجليزية للخارجي فقط، دون قص الإدخال أو حذف رموز منه تلقائيًا.
- الرقم الثاني اختياري وحر الصيغة والطول، ولا يشترط اختلافه عن الأساسي.
- الإنشاء يرسل `second_customer_phone` بعد إزالة المسافات الطرفية، ويحذف الحقل إن كان فارغًا. التعديل يرسل `secondCustomerPhone` وفق عقد PUT في الداشبورد؛ قيمة فارغة تمسح الرقم السابق.
- عند تغيير المنطقة تعاد قواعد التحقق دون تغيير النص المدخل. تظهر الأرقام في المراجعة والتفاصيل، ويظهر اتصال بالرقم الإضافي فقط عندما يصلح كرابط اتصال.
- التطبيع يدعم `secondCustomerPhone` و`second_customer_phone` و`secondPhone`. يضاف الرقم الثاني إلى بصمة مقارنة الطلب لحماية التعديل من تعارض تحديثات أخرى.
- شاشة التعديل الحالية تسمح بالطلبات الداخلية فقط وفق سياسة التطبيق السابقة؛ أضفنا الرقم الثاني وخففنا شرط الهاتف الداخلي دون تغيير صلاحيات تعديل الطلبات الخارجية.

التحقق باستخدام اختبارات الوحدة والواجهة مع بيانات API محاكاة؛ لا تُنشأ طلبات حقيقية.
